# **Аудит проекта: TVC-HAT Backend**

**Дата:** 23 января 2026 г.

**Проверяющий:** GitHub Copilot

**Владелец репозитория:** The Void community

**Краткая сводка:** Проанализировано около 60 файлов в backend. Выявлено 1 лишний файл и 5 модулей, требующих рефакторинга.

---

## **1. Цель**

Выявить неиспользуемые, устаревшие (легаси) файлы и файлы, требующие оптимизации, для очистки репозитория и улучшения поддерживаемости кода backend приложения.

## **2. Методология**

- Анализ импортов и зависимостей в TypeScript файлах.
- Проверка entry points (main.ts) и рекурсивное отслеживание импортов.
- Ручной анализ структуры и ссылок.
- Игнорирование сгенерированных файлов (database/generated/).

## **3. Результаты аудита**

### **3.1. Актуальные и необходимые файлы**

_Файлы, которые активно используются в проекте._

- `src/main.ts` — Entry point приложения.
- `src/app.module.ts` — Главный модуль NestJS.
- `src/app/index.ts`, `src/app/session.app.ts` — Прикладные модули.
- `src/database/prisma.service.ts`, `src/database/schema.prisma` — Сервис базы данных и схема.
- `src/decorators/nullable.decorator.ts`, `src/decorators/public.decorator.ts` — Декораторы, используемые в routes.
- `src/services/env.service.ts`, `src/services/rights.service.ts` — Сервисы окружения и прав.
- `src/utils/create-endpoints.utils.ts`, `src/utils/urlize.utils.ts` — Утилиты для создания endpoints и URL.
- Все файлы в `src/v1/` (v1.module.ts, routes/, services/, guards/, pipes/, etc.) — API v1 модули, активно импортируемые.
- `test/app.e2e-spec.ts` — E2E тесты.

### **3.2. Кандидаты на рефакторинг / Легаси-код**

_Файлы, которые используются, но содержат устаревший код, требуют объединения или оптимизации._

- `test/` — Тестовый модуль, используется для разработки, но может быть оптимизирован или вынесен в отдельное окружение.
- Некоторые DTOs в `v1/routes/*/dto/` — Используются, но могут быть консолидированы для уменьшения дублирования.
- `src/services/env.service.ts` — Логирование может быть улучшено с использованием специализированной библиотеки.

### **3.3. Кандидаты на удаление**

_Файлы, не импортируемые и не используемые в проекте._

- `src/decorators/index.ts` — Индексный файл, не импортируется, так как декораторы импортируются напрямую.
