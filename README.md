# TVC-HAT Frontend

__пока что доступно только описание фронтенда__

## 📱 Современное веб-приложение для общения в реальном времени

TVC-HAT — это современный frontend для чат-платформы, построенный на Next.js 14 с TypeScript. Приложение поддерживает личные и групповые чаты, авторизацию через Google и мгновенный обмен сообщениями через WebSocket.

## 🚀 Основные возможности

- **💬 Мгновенные сообщения** - WebSocket для общения в реальном времени
- **👥 Два типа чатов** - Личные диалоги и групповые чаты
- **🔐 OAuth-авторизация** - Вход через Google аккаунт
- **📱 Адаптивный интерфейс** - Оптимизирован для мобильных устройств
- **🔄 Умная пагинация** - Ленивая загрузка сообщений при скролле
- **📊 Статусы отправки** - Индикаторы отправки, доставки и ошибок
- **🔍 Поиск пользователей** - Модальное окно для поиска и добавления контактов

## 🛠 Технологический стек

- **Next.js 14** - React фреймворк с App Router
- **TypeScript** - Статическая типизация
- **React 18** - Компонентный подход
- **WebSocket** - Соединение в реальном времени
- **Кастомные хуки** - Управление состоянием без внешних библиотек
- **TVUIKit** - Внутренняя UI библиотека компонентов
- **CSS-переменные** - Кастомные свойства для темизации

## 📁 Структура проекта

```
src/
├── app/                    # Страницы Next.js (App Router)
│   ├── page.tsx           # Главная страница
│   ├── home.tsx           # Домашний экран с авторизацией
│   └── chat/              # Раздел чатов
│       ├── page.tsx       # Список чатов
│       └── [chatId]/      # Динамические маршруты чатов
│           └── page.tsx
├── features/              # Бизнес-логика (feature-based)
│   ├── chat/              # Вся логика чатов
│   ├── messages/          # Логика сообщений
│   ├── users/             # Управление пользователями
│   └── client/            # WebSocket клиент
├── components/            # Переиспользуемые UI компоненты
├── hooks/                 # Кастомные React хуки
├── api/                   # REST API клиенты
├── types/                 # TypeScript типы
├── constants/             # Глобальные константы
└── utils/                 # Вспомогательные функции
```

## 🎯 Архитектурные особенности

### Feature-Based Structure
Приложение организовано по доменам (features), что обеспечивает четкое разделение ответственности и упрощает масштабирование.

### Кастомная система состояния
Вместо Redux или Zustand используется собственная реализация на основе хуков React с нормализованным хранением данных.

### WebSocket интеграция
- Динамическое подключение к активным чатам
- Автоматическое переподключение при разрыве
- Синхронизация с REST API

### Оптимизация производительности
- Мемоизация компонентов сообщений
- Ленивая загрузка изображений
- Виртуализация списков сообщений (планируется)

## 🚦 Быстрый старт

### Предварительные требования
- Node.js 18+ 
- npm или yarn
- Бэкенд TVC-HAT (для работы API)

### Установка

```bash
# Клонирование репозитория
git clone [repository-url]
cd tvc-hat-frontend

# Установка зависимостей
npm install
# или
yarn install

# Настройка переменных окружения
cp .env.example .env.local
# Отредактируйте .env.local, указав необходимые значения
```

### Запуск разработки

```bash
npm run dev
# или
yarn dev
```

Приложение будет доступно по адресу: [http://localhost:3000](http://localhost:3000)

### Сборка для продакшена

```bash
npm run build
npm start
# или
yarn build
yarn start
```

## 🎨 Основные компоненты

### Chat Interface
Адаптивный интерфейс чата с выдвижной боковой панелью для мобильных устройств и основным окном переписки.

### Message Component
Компонент сообщения с поддержкой:
- Разных типов контента (текст, изображения, файлы)
- Статусов отправки
- Форматирования времени
- Группировки последовательных сообщений

### User Management
Система управления пользователями с поиском, профилями и статусами онлайн/оффлайн.

## 🔧 Конфигурация

### Переменные окружения
```env
NEXT_PUBLIC_API_URL=http://localhost:8080
NEXT_PUBLIC_WS_URL=ws://localhost:8080
```

Проект использует внутреннюю UI библиотеку, которая предоставляет:

- Индикаторы загрузки
- Систему иконок
- Типографику
